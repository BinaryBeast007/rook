# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and do not harass anyone. This
applies in issues, pull requests, discussions, and any other project space.

## Reporting

To report unacceptable behavior, contact the maintainers privately through the email on the
[maintainer's GitHub profile](https://github.com/BinaryBeast007). All reports are reviewed and kept
confidential. Maintainers may remove contributions or block participants who break these rules.
